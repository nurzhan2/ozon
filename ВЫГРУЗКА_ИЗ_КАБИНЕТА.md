# Выгрузка из кабинета OZON: что нужно и куда класть

Четыре строки отчёта «Качественные показатели» — **показы, клики, корзина и
% корзины** — через API получить нельзя. OZON отдаёт их только продавцам с
подпиской Premium Plus, а обходных путей нет: проверены все методы аналитики,
поиска по запросам и готовых отчётов.

В кабинете эти цифры есть. Поэтому раз в день их нужно выгрузить файлом и
положить в общую папку — дальше всё происходит само.

Занимает минуту. Если файл не положить, отчёт всё равно соберётся, просто эти
строки останутся пустыми с пояснением под таблицей.

---

## Что выгружать

В кабинете продавца: **Аналитика → Графики** (в некоторых кабинетах раздел
называется «Аналитика → Отчёты» или «Товары в поиске»).

Настройте отчёт так:

**Группировка (разрезы):** «День» **и** «Товар» — обязательно оба.

Это самое важное. Если оставить только «Товар», OZON выдаст одну строку на
товар за весь период, без разбивки по дням. Такой файл не подойдёт: отчёт
подневный, а размазывать период по дням нельзя — получатся выдуманные числа.
Программа такой файл не примет и напишет об этом в лог.

**Показатели:** «Показы», «Сессии» (или «Уникальные посетители»), «В корзину»,
«Позиция в поиске». Если каких-то нет — берите те, что есть, остальные строки
просто останутся пустыми.

**Период:** с 1-го числа текущего месяца по вчерашний день. Сегодняшний день
OZON ещё не посчитал, его можно не включать.

**Формат:** XLSX или CSV — оба подходят.

---

## Куда класть

В общей папке Google Диска (ссылку пришлём отдельно) лежит по подпапке на
каждый магазин:

```
Выгрузки OZON/
├── СЕКРЕТЫ КРАСОТЫ/
├── БЬЮТИФУЛ/
├── ДАЙМОНД/
├── ЛИНИЯ МЕЧТЫ/
└── ШТУЧКА/
```

Скачанный файл перетащите в подпапку своего магазина. Всё.

Переименовывать не нужно, старые файлы удалять не нужно — программа берёт
самый свежий по дате изменения. Имена подпапок менять нельзя: по ним
определяется магазин.

---

## Когда класть

До 8 утра по Москве — в это время собирается утренний пакет отчётов.

Если выгрузка окажется вчерашней или позавчерашней, ничего страшного не
случится: заполнятся те дни, которые в ней есть, остальные останутся пустыми.

---

## Как проверить, что сработало

В логе сбора появится строка вида:

```
[СЕКРЕТЫ КРАСОТЫ] выгрузка кабинета с Диска: report.xlsx (2026-08-08), товаров 14
```

А в отчёте 3 строки «показы», «клики», «корзина» и «% корзины» заполнятся, и
из-под таблицы пропадёт блок «Почему эти строки пустые». Заодно из названий
строк исчезнет пометка «(реклама)»: пока выгрузки нет, клики берутся только из
рекламного отчёта, а с ней — настоящие, все.

Если что-то пошло не так, в логе будет сказано, что именно: не нашлась
подпапка, не разобралась шапка файла или в выгрузке нет разбивки по дням.

## Настройка со стороны проекта (делается один раз)

1. Создать на Google Диске папку с подпапками по именам магазинов —
   в точности как в `OZON_STORES`.
2. Открыть к папке доступ сервисному аккаунту (его почта печатается при
   запуске выгрузки в Google Таблицы) — достаточно прав «Читатель».
3. Тому, кто будет класть файлы, дать права «Редактор».
4. Скопировать ID папки из адресной строки:
   `https://drive.google.com/drive/folders/`**`1AbC...XyZ`** — нужен
   выделенный кусок.
5. Прописать его в Railway → Variables:

```
GOOGLE_IMPORT_FOLDER=1AbC...XyZ
```

Локально файлы можно класть и без Диска — в `DATA_DIR/import/<Магазин>/`.
Диск проверяется первым, локальная папка — запасной вариант.
