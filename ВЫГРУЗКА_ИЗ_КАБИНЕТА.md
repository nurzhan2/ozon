# Выгрузка из кабинета OZON: что нужно и куда класть

Две строки отчёта «Качественные показатели» — **корзина и % корзины** — через
API получить нельзя ничем: OZON отдаёт их только продавцам с подпиской
Premium Plus. Выгрузка заодно уточняет строки «клики» и «CTR»: без неё они
считаются только по рекламе.

В кабинете эти цифры есть. Поэтому раз в день их нужно выгрузить файлом и
положить в общую папку — дальше всё происходит само.

Занимает минуту. Если файл не положить, отчёт всё равно соберётся, просто эти
строки останутся пустыми с пояснением под таблицей.

---

## Что выгружать

В кабинете продавца: **Аналитика → Графики**.

**Показатели:** «Уникальные посетители, всего», «Уникальные посетители
с просмотром карточки товара», «Конверсия в корзину из карточки товара»,
«Позиция в поиске и каталоге». Если в списке есть «В корзину» в штуках —
отметьте и её, будет точнее.

Ровно этот набор и был в первой присланной выгрузке, менять его не нужно.

**Группировка:** «Только товары».

**Период: ОДИН ДЕНЬ.** Вчерашний.

Это главное и единственное, что важно. Конструктор отчётов в кабинете не
умеет разбивать данные по дням — в настройке группировок есть только товары,
бренды и категории. Поэтому выгрузка за неделю приходит одной строкой на
товар за всю неделю, и разложить её по дням невозможно.

Значит: один файл — один день. Ставите период «вчера», скачиваете, и завтра
то же самое.

**Имя файла: дата этого дня.** Например `2026-08-08.xlsx`. Программа берёт
день именно из имени, больше его в файле взять негде. Подойдут и
`08.08.2026.xlsx`, и `20260808.xlsx`.

**Формат:** XLSX или CSV — оба подходят.

Первый раз, чтобы заполнить текущий месяц, придётся выгрузить по файлу на
каждый прошедший день. Дальше — один файл в день, минута.

---

## Куда класть

В общей папке Google Диска (ссылку пришлём отдельно) лежит по подпапке на
каждый магазин:

```
Выгрузки OZON/
├── СЕКРЕТЫ КРАСОТЫ/
├── БЬЮТИФУЛ/
├── ДАЙМОНД/
├── ЛИНИЯ МЕЧТЫ/
└── ШТУЧКА/
```

Скачанный файл, названный датой, перетащите в подпапку своего магазина. Всё.

Старые файлы удалять не нужно — программа читает их все и собирает из них
период. Имена подпапок менять нельзя: по ним определяется магазин.

---

## Когда класть

До 8 утра по Москве — в это время собирается утренний пакет отчётов.

Если выгрузка окажется вчерашней или позавчерашней, ничего страшного не
случится: заполнятся те дни, которые в ней есть, остальные останутся пустыми.

---

## Как проверить, что сработало

В логе сбора появится строка вида:

```
[СЕКРЕТЫ КРАСОТЫ] выгрузка кабинета с Диска: файлов 8, дней 8, товаров 14
```

А в отчёте 3 строки «показы», «клики», «корзина» и «% корзины» заполнятся, и
из-под таблицы пропадёт блок «Почему эти строки пустые». Заодно из названий
строк исчезнет пометка «(реклама)»: пока выгрузки нет, клики берутся только из
рекламного отчёта, а с ней — настоящие, все.

Если что-то пошло не так, в логе будет сказано, что именно: не нашлась
подпапка, не разобралась шапка файла или в имени файла нет даты.

## Настройка со стороны проекта (делается один раз)

1. Создать на Google Диске папку с подпапками по именам магазинов —
   в точности как в `OZON_STORES`.
2. Открыть к папке доступ сервисному аккаунту (его почта печатается при
   запуске выгрузки в Google Таблицы) — достаточно прав «Читатель».
3. Тому, кто будет класть файлы, дать права «Редактор».
4. Скопировать ID папки из адресной строки:
   `https://drive.google.com/drive/folders/`**`1AbC...XyZ`** — нужен
   выделенный кусок.
5. Прописать его в Railway → Variables:

```
GOOGLE_IMPORT_FOLDER=1AbC...XyZ
```

Локально файлы можно класть и без Диска — в `DATA_DIR/import/<Магазин>/`.
Диск проверяется первым, локальная папка — запасной вариант.
